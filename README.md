# 🧑‍💼 Job Portal Application (Django + Bootstrap)

A full-featured job portal where employers can post jobs and job seekers can search, view, and apply for jobs. Built with Django and styled using Bootstrap.

---

## 🚀 Features

| Feature                | Description                                                |
| ----------------------| ---------------------------------------------------------- |
| 🧍 Register            | Job seekers and employers can register                     |
| 🔐 Login/Logout        | Secure login/logout system with role-based access          |
| 📝 Post Job (Employer) | Employers can post jobs with all necessary details         |
| 🔍 Search Jobs         | Filter jobs by title, location, and company                |
| 📄 Job Detail Page     | View complete job description and employer info            |
| 📎 Apply to Job        | Upload resume and apply to jobs as a seeker                |
| 🧑‍💼 Admin Panel       | Superuser can manage users, jobs, and applications          |

## 🛠️ Tech Stack

- **Backend:** Django 5+
- **Frontend:** Bootstrap 5, HTML, CSS
- **Database:** SQLite (can be upgraded to PostgreSQL)
- **Other:** Django Admin, Static files, File uploads
